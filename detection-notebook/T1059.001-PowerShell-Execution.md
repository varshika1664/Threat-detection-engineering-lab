# T1059.001 — PowerShell Execution

## Technique Overview

| Field | Detail |
|---|---|
| ATT&CK ID | T1059.001 |
| Tactic | Execution |
| Platform | Windows |
| Test date | 2026-07-27 |

## Atomic Test Used

Tool: Atomic Red Team
Command: `Invoke-AtomicTest T1059.001`

## What the test does

Executes PowerShell with encoded commands and spawns cmd.exe as a child
process — replicating how attackers use PowerShell to evade script-block
logging while maintaining execution capability.

## Log Source

- Channel: Microsoft-Windows-Sysmon/Operational
- Event ID: 1 (ProcessCreate)
- Key fields: CommandLine, ParentImage, Image, User

## False Positive Considerations

| Scenario | Likelihood |
|---|---|
| Legitimate admin scripts calling cmd from PS | Medium |
| Build pipelines / CI scripts | Low |
| Developer tooling | Low |

**Mitigation:** Correlate with user account (is it a service account?),
time of day (3am = suspicious), and whether ParentImage chain goes
higher (e.g. Word → PowerShell → cmd = high confidence malicious).
