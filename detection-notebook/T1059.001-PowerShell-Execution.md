# T1059.001 — PowerShell Execution

## Technique Overview

| Field | Detail |
|---|---|
| ATT&CK ID | T1059.001 |
| Tactic | Execution (TA0002) |
| Sub-technique | PowerShell |
| Platform | Windows |
| Test date | 2026-07-27 |

## Atomic Test Used

- Tool: Atomic Red Team (Invoke-AtomicRedTeam)
- Command: `Invoke-AtomicTest T1059.001`
- Cleanup: `Invoke-AtomicTest T1059.001 -Cleanup`

## What the test does

Executes PowerShell with encoded commands and spawns cmd.exe as a child
process — replicating how attackers use PowerShell to evade script-block
logging while maintaining execution capability.

## False Positive Considerations

| Scenario | Likelihood |
|---|---|
| Legitimate admin scripts calling cmd from PowerShell | Medium |
| Build pipelines / CI-CD scripts | Low |
| Developer tooling (VS Code terminal) | Low |

**Mitigation:** Correlate with user context (is it a service account?),
time of day (off-hours = higher risk), and full parent process chain
(Word → PowerShell → cmd = high confidence malicious).
